## 2. Decision tables

### 2.1 Cell representation (`Mem`)
| C | Rust | decision |
|---|---|---|
| `flags & MEM_Null/Str/Int/Real/Blob/IntReal/Zero/Subtype/Cleared/FromBind` | same bit values in `Mem.flags` | every opcode tests the same bits in the same order |
| `MEM_Dyn/Static/Ephem/Term` (who owns `z`) | none: `z: Vec<u8>` is always owned | `OP_SCopy` / `OP_Copy` / `OP_Column` copy the bytes; `Deephemeralize` is a no-op |
| `u.i`, `u.r`, `u.nZero` (a union) | three fields | no opcode reads a member it did not write |
| `enc` | always UTF-8 | UTF-16 databases are not run by the machine |
| `MEM_Agg` + `z` = aggregate context | `MEM_AGG` + side table `Vdbe.a_agg[reg]` | a register reset by `OP_Null` loses its accumulator at the next `OP_AggStep` (C: `vdbeMemClearExternAndSetNull`) |
| RowSet in a register (`MEM_Blob\|MEM_Dyn`, `xDel=sqlite3RowSetDelete`) | `MEM_BLOB` + side table `Vdbe.a_rowset[reg]` | `(flags & MEM_Blob)==0` creates the set, as in C |

### 2.2 Affinity (`applyAffinity(pRec, aff)`)
| affinity | cell | action |
|---|---|---|
| ≥ NUMERIC (NUMERIC, INTEGER, REAL, FLEXNUM) | has `MEM_Int` | nothing |
| | `MEM_Str`, no `Real`/`IntReal` | `applyNumericAffinity(pRec, 1)`: `sqlite3AtoF` rc ≤ 0 → unchanged; rc without bit 2 and `alsoAnInt` → `MEM_Int`; else `MEM_Real` then `sqlite3VdbeIntegerAffinity`; **`MEM_Str` is cleared** |
| | `MEM_Real`/`IntReal`, affinity ≤ REAL | `sqlite3VdbeIntegerAffinity` (real → int when the round trip is exact and not ±2^63) |
| TEXT | no `MEM_Str`, has `Int`/`Real`/`IntReal` | `sqlite3VdbeMemStringify(.., 1)` (`%!.17g` / integer text / `N.0` for IntReal) |
| | always | `flags &= ~(Real\|Int\|IntReal)` |
| BLOB / NONE | | nothing |
`OP_Affinity`: after REAL affinity an `Int` becomes `Real`. `OP_MakeRecord`: after REAL affinity an `Int` becomes `IntReal` (stored as integer when it fits 6 bytes, serial type 7 otherwise).

### 2.3 Comparison (`OP_Eq` … `OP_Ge`)
| case | decision |
|---|---|
| both `MEM_Int` | integer compare; jump per `sqlite3aLTb/EQb/GTb`; `iCompare` set |
| a NULL, `SQLITE_NULLEQ` | equal only if both NULL and P3 is not `MEM_Cleared`; else `res = P3 NULL ? -1 : +1` |
| a NULL, no `NULLEQ` | jump iff `SQLITE_JUMPIFNULL`; `iCompare = 1` |
| affinity (P5 & 0x47) ≥ NUMERIC and a `MEM_Str` operand | `applyNumericAffinity(.., 0)` on the pure-string operands |
| affinity TEXT and a `MEM_Str` operand | numeric operands are stringified (forced) |
| then | `sqlite3MemCompare(pIn3, pIn1, P4 collation)`; the flags of both operands are restored |
`sqlite3MemCompare`: NULL < numbers < text < blob; int/int, real/real, `sqlite3IntFloatCompare` for mixed; text by the collation (`CollRt.cmp`), without one `sqlite3BlobCompare` (with the `MEM_Zero` rules).
`OP_Compare`: per field `aColl[i]`, `KEYINFO_ORDER_DESC` reverses, `KEYINFO_ORDER_BIGNULL` reverses when a NULL is involved; permutation from the preceding `OP_Permutation`.

| C | Rust | decision |
|---|---|---|
| `pC->cacheStatus != p->cacheCtr` | `pc_.cache_status != self.cache_ctr` | refill: `payloadSize`, `aRow`/`szRow` (`sqlite3BtreePayloadFetch`), header size, `nHdrParsed = 0` |
| `p->cacheCtr = (cacheCtr+2)\|1` at `OP_ResultRow`; `CACHE_STALE` (0) set by every opcode that moves the cursor | same | |
| pseudo-cursor with `nullRow` and `seekResult>0` | same | the row is the register `seekResult` |
| `deferredMoveto` | same | `aAltMap[1+p2] > 0` → read from the index cursor (`pAltCursor`); else `sqlite3VdbeFinishMoveto` (`sqlite3BtreeTableMoveto`; `res!=0` → SQLITE_CORRUPT) |
| `sqlite3BtreeCursorHasMoved` | `BtCursor::has_moved` | `sqlite3VdbeHandleMovedCursor`, restart |
| `szRow < aOffset[0]` | same | header read through `sqlite3VdbeMemFromBtreeZeroOffset`; > 98307 or > payloadSize → corrupt |
| header parse loop up to column P2 | same | corrupt if the header overruns or the data size disagrees with `payloadSize` |
| column missing | same | `P4_MEM` default or NULL |
| `szRow >= aOffset[p2+1]` | same | decoded from the page copy |
| else, P5 typeof/length flags or zero-length | same | type and length only ("content is irrelevant") |
| else | `vdbeColumnFromOverflow` | > 4000 bytes on a table cursor: `VdbeTxtBlbCache` keyed by (column, `cacheStatus`, `colCacheCtr`, `sqlite3BtreeOffset`); otherwise `sqlite3VdbeMemFromBtree` → `accessPayload` |

### 2.5 Seek opcodes
| opcode | decision |
|---|---|
| `OP_SeekLT/LE/GE/GT`, table | P3 string → `applyNumericAffinity`; not integer: NULL or (not real and ≥ SeekGE) → jump; not real and < SeekGE → `sqlite3BtreeLast`; real: `sqlite3IntFloatCompare` turns GT↔GE / LT↔LE; `sqlite3BtreeTableMoveto`; `movetoTarget` |
| …, index | `UnpackedRecord{nField = P4, default_rc = (oc is LE or GT) ? -1 : +1, eqSeen = 0}`; `sqlite3BtreeIndexMoveto`; with `BTREE_SEEK_EQ` and `eqSeen==0` → not found |
| then | GE/GT: `res<0 \|\| (res==0 && GT)` → `sqlite3BtreeNext`; LT/LE: `res>0 \|\| (res==0 && LT)` → `sqlite3BtreePrevious`, else `sqlite3BtreeEof`; found with `eqOnly` → skip the next opcode |
| `OP_SeekScan` | up to P1 `sqlite3BtreeNext` steps comparing with `sqlite3VdbeIdxKeyCompare`; `res>0 && P5==0` → jump to the P2 of the following `OP_SeekGE`; `res>=0` → jump to P2 |
| `OP_SeekHit` | clamp `seekHit` to [P2, P3] |
| `OP_IfNoHope` | `seekHit >= P4` → fall through; else as `OP_NotFound`, and on a hit `seekHit = P4` |
| `OP_Found/NotFound/NoConflict` | P4>0: key in registers, else the record in P3 unpacked; `seekResult` = result of `sqlite3BtreeIndexMoveto`; `nullRow = !found`; NoConflict jumps when a key field is NULL |
| `OP_SeekRowid` | P3 not integer: string → `applyNumericAffinity(.., 1)` on a copy; not an exact integer → jump |
| `OP_NotExists` / SeekRowid | `sqlite3BtreeTableMoveto(.., 0, &res)`; `seekResult = res`; `res!=0` → jump (P2==0: corrupt) |
| `OP_DeferredSeek` / `OP_IdxRowid` | `sqlite3VdbeCursorRestore`; not `nullRow`: `sqlite3VdbeIdxRowid` (last field of the key); DeferredSeek sets `movetoTarget`, `deferredMoveto`, `aAltMap`, `pAltCursor` on the table cursor |
| `OP_IdxLE/GT/LT/GE` | `default_rc = (opcode < OP_IdxLT) ? -1 : 0`; `sqlite3VdbeRecordCompareWithSkip`; LT/GE use `-res`, LE/GT use `res+1`; jump if > 0 |
| `OP_Rewind/Last/Next/Prev` | `sqlite3BtreeFirst/Last/Next/Previous`; `nullRow`; `aCounter[P5]++` on a step |

### 2.6 Record comparators
| C | decision |
|---|---|
| `sqlite3VdbeFindCompare` | ≤ 13 fields, first sort flag without BIGNULL: `r1/r2 = ∓1` (±1 for DESC); first value `MEM_Int` → `vdbeRecordCompareInt`; first value a string with BINARY collation → `vdbeRecordCompareString`; else the general comparator |
| `sqlite3VdbeRecordCompareWithSkip` | per field by the type of the right-hand value (int, real, string, blob, NULL), serial type of the left; first difference: reversed for DESC, and for BIGNULL only when (DESC) ≠ (a NULL is involved); all compared fields equal → `default_rc`, `eqSeen = 1` |
| corrupt record | `errCode` set, result 0; `sqlite3BtreeIndexMoveto` returns SQLITE_CORRUPT on an exact hit with `errCode` |

| C | Rust | decision |
|---|---|---|
| `pKeyInfo->nKeyField = nField` (P3) | same | only the sort columns are compared |
| record list, newest at the head | `list` in insertion order, walked in reverse | |

## 5. What is different from C by construction, and what is not ported

| item | C | here | observable? |
|---|---|---|---|
| stepping | `sqlite3_step` returns at every `OP_ResultRow` | the engine's read step runs the machine to its end and keeps the rows (as its executor does: `RunningExec::MaterializedRead`); `Vdbe::exec` itself is resumable (`pc`, `Ok(true)` per row) | memory for large results; interleaving of two statements stepped alternately through the API (not through the CLI) |
| error after rows | rows already stepped stay delivered, the error is returned by the next step | same (rows are delivered, then the error) | no |
| `iCompare`, `colCacheCtr` (locals of `sqlite3VdbeExec`) | start again at every `sqlite3_step` | reset only when `exec` is entered: with the engine's wiring `exec` is entered once per row, so the same | no |
| text encoding | UTF-8 / UTF-16 | UTF-8 only; UTF-16 databases stay on the engine's executor | no (fallback) |
| text that is not valid UTF-8 | bytes | bytes inside the machine; U+FFFD when a value is handed to an engine function or to the caller (`Value::Text` is a `String`) | yes — engine-wide limitation (E4) |
| functions | C's `func.c`, `date.c`, `json.c`, … | the engine's implementations by name (`min` / `max` / `nullif` ported) | where the engine's function differs from C (E3) |
| aggregate context | `sqlite3_aggregate_context` in the cell | engine accumulator by handle | no |
| ephemeral b-tree | temp file when the cache spills | always in memory | no (memory) |
| sorter PMAs | temp files, `MergeEngine` | sorted runs in memory, pairwise merge with the same tie rule | no (memory) |
| `sqlite3VdbeHalt` transaction end | `vdbeCommit` / statement end | the engine's `finish_activity` | no (page-cache traces equal) |
| progress handler | every `nProgressOps` instructions | the engine's tick at every `check_for_interrupt` point | callback count |
| `sqlite3_stmt_status` counters | `aCounter[]` | counted in `Vdbe.a_counter`, not published | API only |
| authorizer | asked by the generator | connections with an authorizer stay on the engine's executor | no (fallback) |
| application-defined collations | `xCmp` | connections whose schema declares one stay on the engine's executor | no (fallback) |
| trace callbacks (`OP_Init` / `OP_Trace`) | `sqlite3_trace_v2` | not called | API only |
